# davidcasalsite

One-page teaser site for the novel (working title *Arrivals*) by **David Casal**.

- `index.html` — self-contained page (hero image inlined; clickable hero opens a lightbox that plays `arrivals-teaser.mp4`).
- `.cpanel.yml` — Krystal/cPanel deployment: copies files to davidcasal.uk's document root on **Deploy HEAD Commit**.

## Deploy
Edit → commit → push. In cPanel → Git Version Control → **Update from Remote**, then **Deploy HEAD Commit**.
